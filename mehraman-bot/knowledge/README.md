# پوشه‌ی محتوای پشتیبان

فایل‌های `.md` یا `.txt` این پوشه، مبنای پاسخ‌گویی بازو هستند. نکته‌ها:

- محتوای داخلی/محرمانه (مثل متن «محتوای پشتیبان» خانواده) **در گیت نمی‌رود** (در `.gitignore` است). روی سرور بگذارید یا با ارسال فایل به بازو (`/addknowledge`) اضافه کنید.
- تبدیل docx/pdf: `python -m mehraman_bot.ingest فایل.docx --title "عنوان"`
- بعد از تغییر فایل‌ها: در بله `/reload` را بفرستید (ادمین).
- راهنمای ارتقا با هوش مصنوعی: `docs/UPDATING_WITH_AI.md`
