# بازوی مهرمان (بله)

دستیار هوشمند مهرمان برای بله: **پرسش‌وپاسخ در چارچوب فکری مهرمان**، **پشتیبانی از دوره (تمرین/یادآوری/چک‌این)**، **پروفایل و نقشه‌ی رشد ساده** و **ارجاع به مشاور**.

## قابلیت‌ها

- **پاسخ‌گویی مبتنی بر محتوای شما**: محتوای پشتیبان (`knowledge/`) در پرامپت بازیابی می‌شود؛ مدل اجازه ندارد از دانش عمومی ادعای تازه بسازد، محتوا را نقل مستقیم کند یا چارچوب دینی/نظری پشت‌صحنه را آشکار بگوید. اگر مطلب مرتبطی نباشد: پاسخ «خارج از دامنه» + پیشنهاد مشاور، و پرسش برای گزارش خلأ محتوایی ثبت می‌شود.
- **ایمنی**: کلیدواژه‌های اضطراری (آسیب به خود، خشونت…) بدون مدل، پاسخ ثابت با شماره‌های اضطراری می‌دهند؛ موضوعات بالینی (طلاق، خیانت، وسواس…) دکمه‌ی ارجاع می‌گیرند؛ مدل هم با نشانه‌ی `[[REFER]]` می‌تواند ارجاع را فعال کند.
- **ارجاع به مشاور**: فرم ۴ پرسشه‌ی کوتاه ← ارسال به `REFERRAL_CHAT_ID` (مسئول ارجاع).
- **نقشه‌ی رشد (نسخه‌ی ۰.۱)**: هر کاربر یک پروفایل دارد: ایستگاه فعلی، پیشرفت تمرین‌ها، کارهای هفته، ایستگاه بعد. (تحلیل گلوگاه و فرضیه‌سازی عمداً هنوز پیاده نشده؛ طبق سند معماری هنوز منتظر نسخه‌ی مبنای دو الگوی مادر هستیم.)
- **تمرین و یادآوری**: «تمرین امروز» از کاربرگ‌ها (یا اگر کاربرگی نبود، تمرین پیشنهادیِ تولیدشده از محتوای ایستگاه)، یادآوری روزانه با ساعت دلخواه، **چک‌این سه‌گزینه‌ای** (انجام شد / تا حدی / هنوز نه + مانع).
- **ادمین**: `/stats` (کاربران، پرسش‌ها، چک‌این، موانع، پرسش‌های بی‌پاسخ)، `/reload`, `/sources`, آپلود فایل محتوا مستقیم در بله.

## استقرار روی سرور B (کانتینر)

روی سرور B (با Docker و git) فقط این را اجرا کنید؛ توکن‌ها را خودش به‌صورت مخفی می‌پرسد و در `/opt/mehraman/mehraman-bot/.env` (دسترسی ۶۰۰) می‌گذارد:

```bash
curl -fsSL https://raw.githubusercontent.com/rokni2005/3x-ui/ccr-49cdcaf2-vrb055/mehraman-bot/deploy/deploy-serverB.sh -o deploy.sh
bash deploy.sh
```

(اگر مخزن خصوصی است، اول مخزن را `git clone` کنید و `bash mehraman-bot/deploy/deploy-serverB.sh` را بزنید.) بروزرسانی کد بعدی: همان `bash deploy.sh`. لاگ: `docker compose logs -f`.

## مدیریت بدون کد

کاربران و ادمین همه‌چیز را با دکمه انجام می‌دهند. ادمین از دکمه‌ی «🛠 پنل مدیریت»: گزارش، افزودن محتوای پشتیبان (متن یا فایل Word/md)، افزودن کاربرگ (ویزارد: ایستگاه ← عنوان ← گام‌ها)، حذف منابع و بارگذاری مجدد. نیازی به YAML یا دستور نیست (دستورهای `/…` فقط میان‌بُرند).

## راه‌اندازی دستی (بدون Docker)

```bash
cd mehraman-bot
cp .env.example .env      # توکن بله، کلید مدل، ADMIN_IDS، REFERRAL_CHAT_ID را پر کنید
pip install -r requirements.txt
python -m mehraman_bot.main --check   # بررسی تنظیمات و اتصال به بله
python -m mehraman_bot.main
```

با Docker: `docker compose up -d --build` (پوشه‌ی `data/` ماندگار است).

**توکن بازو را هرگز در گیت، چت یا README نگذارید.** فقط در `.env` (که `.gitignore` شده). اگر توکن جایی دیده شده، از BotFather بله بازسازی (Regenerate) کنید.

شناسه‌ی عددی ادمین: از یک بازوی «شناسه‌یاب» بله یا لاگ همین بازو (پیام‌دادن به بازو → `chat.id`) بگیرید.

## معماری (مطابق سند «بازو فقط رابط است»)

بازو رابط تعامل است، نه جای ماندگاری قفل‌شده‌ی منطق: محتوا در فایل، داده در SQLite پشت لایه‌ی `db.py`، مدل پشت `llm.py`. بعداً وب‌اپ/PWA می‌تواند همین محتوا و داده را بخواند. اطلاعات حساس در متن آزاد جمع نمی‌شود: فرم ارجاع حداقلی است و به کاربر هشدار می‌دهد نام/مشخصات هویتی ننویسد.

## نکته‌های استقرار

- **دسترسی شبکه**: سرور باید هم به `tapi.bale.ai` و هم به سرویس مدل برسد. بسیاری از سرویس‌های مدل از سرورهای داخل ایران در دسترس نیستند؛ راه‌حل‌ها: سرور خارج از ایران، `LLM_PROXY`، یا `LLM_PROVIDER=openai` با `LLM_BASE_URL` یک گیت‌وی سازگار.
- **حریم خصوصی**: متن پرسش‌ها به سرویس مدل می‌رود (در پیام خوش‌آمد به کاربر گفته می‌شود). تاریخچه‌ی هر کاربر فقط ۱۲ پیام آخر نگه داشته می‌شود؛ `/reset` آن را پاک می‌کند.
- **نمایش در جست‌وجوی بله**: بازو با کمتر از ۲۰ کاربر ماهانه در جست‌وجو دیده نمی‌شود؛ لینک مستقیم `ble.ir/Mehremanbot` را در کانال بگذارید.
