# استقرار روی سرور

این اسکریپت‌ها برای نصب/به‌روزرسانی ربات روی یک سرور لینوکسی (دبیان/اوبونتو) هستند.
چون این Claude Code session به‌دلیل سیاست شبکه‌اش امکان اتصال SSH مستقیم به سرور شما را
ندارد، این دستورات باید توسط خودتان (یا سشن دیگری که به سرور دسترسی SSH دارد) روی خود
سرور اجرا شوند.

## نصب اولیه

روی سرور، به‌عنوان root:

```bash
curl -fsSL https://raw.githubusercontent.com/rokni2005/3x-ui/claude/bale-fruit-order-bot-w2lyzu/balebot/deploy/setup.sh -o setup.sh
chmod +x setup.sh
./setup.sh
```

(یا اگر ریپازیتوری را از قبل کلون کرده‌اید: `balebot/deploy/setup.sh` را مستقیم اجرا کنید.)

اسکریپت به‌صورت خودکار:
- در صورت نبود، Go را نصب می‌کند (بدون نیاز به gcc/CGO).
- یک کاربر سیستمی `balebot` می‌سازد.
- سورس را در `/opt/balebot/src` کلون/آپدیت و در `/opt/balebot/bin/balebot` می‌سازد.
- فایل تنظیمات را در `/etc/balebot/balebot.env` (از روی `balebot.env.example`) می‌سازد —
  **این فایل را باز کنید و مقادیر واقعی (توکن ربات، رمز ادمین و ...) را وارد کنید.**
- سرویس systemd را نصب می‌کند (بدون روشن کردن، چون هنوز تنظیمات کامل نیست).

بعد از پر کردن `/etc/balebot/balebot.env`:

```bash
systemctl enable --now balebot
journalctl -u balebot -f
```

## به‌روزرسانی بعدی

هر وقت کد تغییر کرد، فقط دوباره همان اسکریپت را اجرا کنید؛ چون `balebot.env` از قبل
وجود دارد، این‌بار فقط کد را آپدیت، دوباره build و سرویس را ری‌استارت می‌کند (تنظیمات
شما دست‌نخورده می‌ماند):

```bash
/opt/balebot/src/balebot/deploy/setup.sh
```

## دسترسی به پنل ادمین

پنل ادمین فقط روی `127.0.0.1:8080` خود سرور گوش می‌دهد. از سیستم خودتان:

```bash
ssh -L 8080:127.0.0.1:8080 <user>@62.60.193.76
```

و سپس در مرورگر: `http://127.0.0.1:8080/fruits`
