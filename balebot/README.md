# ربات سفارش آنلاین میوه (بله)

یک ربات مستقل برای پیام‌رسان **بله** که به مشتری‌ها امکان می‌دهد میوه سفارش بدهند:
انتخاب میوه از لیست، تعیین وزن، مشاهده سبد خرید، ثبت آدرس و شماره تماس، مشاهده فاکتور
و پرداخت ودیعه.

این پروژه کاملاً مستقل از پنل ۳X-UI است (ماژول Go جداگانه، بدون هیچ وابستگی بیرونی؛
فقط از کتابخانه استاندارد Go استفاده می‌کند) و صرفاً درون همین ریپازیتوری نگه‌داری می‌شود.

## سناریوی گفتگو

1. `/start` → نمایش لیست میوه‌ها به صورت دکمه‌های شیشه‌ای (inline keyboard).
2. با زدن روی یک میوه، قیمت هر کیلو و یک انتخاب‌گر وزن (➖ / ➕ با گام ۰.۵ کیلوگرم) نشان
   داده می‌شود؛ با زدن «افزودن به سبد خرید» آن قلم به سبد اضافه می‌شود.
3. کاربر می‌تواند چند میوه مختلف اضافه کند و در نهایت روی «مشاهده سبد خرید و ثبت سفارش»
   بزند.
4. سپس آدرس کامل و شماره تماس به صورت پیام متنی از کاربر گرفته می‌شود.
5. فاکتور نهایی نمایش داده می‌شود: ریز اقلام، جمع کل، یادآوری «ارسال ما رایگانه»،
   مبلغ ثابت ودیعه (پیش‌فرض ۲۰۰,۰۰۰ تومان) و مابقی مبلغ که پس از تحویل سفارش دریافت
   می‌شود.
6. با زدن دکمه پرداخت ودیعه، شماره کارت برای واریز نمایش داده می‌شود؛ کاربر تصویر رسید
   را ارسال می‌کند، سفارش نهایی شده و (در صورت تنظیم) خلاصه سفارش + تصویر رسید برای چت
   مدیر ارسال می‌شود.

> توجه: این نسخه اول، وضعیت سفارش‌ها را فقط در حافظه نگه می‌دارد (بدون پایگاه داده) و
> پرداخت ودیعه از طریق واریز کارت‌به‌کارت و ارسال رسید انجام می‌شود، نه یک درگاه پرداخت
> آنلاین. برای اتصال به درگاه پرداخت واقعی (مثل زرین‌پال) نیاز به اطلاعات پذیرنده و کار
> اضافه‌تری است.

## ساخت و اجرا

```bash
cd balebot
go build -o balebot .
```

متغیرهای محیطی:

| متغیر | الزامی | توضیح |
|---|---|---|
| `BALE_BOT_TOKEN` | بله | توکن ربات، از طریق ربات «BotFather» در بله ساخته می‌شود. |
| `ADMIN_CHAT_ID` | خیر | شناسه چت مدیر/فروشنده برای دریافت خودکار سفارش‌های جدید و تصویر رسید. |
| `DEPOSIT_AMOUNT` | خیر | مبلغ ودیعه به تومان (پیش‌فرض `200000`). |
| `DEPOSIT_CARD_NUMBER` | خیر | شماره کارت مقصد واریز ودیعه. |
| `DEPOSIT_CARD_HOLDER` | خیر | نام صاحب کارت. |

اجرا:

```bash
BALE_BOT_TOKEN="..." \
ADMIN_CHAT_ID="123456789" \
DEPOSIT_CARD_NUMBER="6037-xxxx-xxxx-xxxx" \
DEPOSIT_CARD_HOLDER="نام و نام خانوادگی" \
./balebot
```

ربات با استفاده از long polling (`getUpdates`) اجرا می‌شود و نیازی به وب‌هوک یا دامنه
عمومی ندارد؛ برای اجرای دائمی می‌توانید آن را به‌صورت یک سرویس systemd یا کانتینر
داکر جداگانه در کنار پنل اجرا کنید.

## تغییر یا افزودن میوه‌ها

لیست میوه‌ها و قیمت هر کیلو در `bot/catalog.go` تعریف شده و به سادگی قابل ویرایش است.
