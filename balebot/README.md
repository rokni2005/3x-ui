# ربات سفارش آنلاین میوه (بله)

یک ربات مستقل برای پیام‌رسان **بله** که به مشتری‌ها امکان می‌دهد میوه سفارش بدهند:
انتخاب میوه از لیست، تعیین وزن، مشاهده سبد خرید، ثبت آدرس و شماره تماس، مشاهده فاکتور
و پرداخت ودیعه. قیمت‌ها، حداقل وزن قابل سفارش هر میوه و سفارش‌های ثبت‌شده در یک پایگاه
داده SQLite ذخیره می‌شوند و از یک پنل ادمین تحت وب قابل مدیریت‌اند.

این پروژه کاملاً مستقل از پنل ۳X-UI است (ماژول Go جداگانه، بدون دست‌زدن به کد پنل یا
ربات تلگرام ادمین موجود) و صرفاً درون همین ریپازیتوری نگه‌داری می‌شود. تنها وابستگی
بیرونی، درایور Go خالص SQLite (`modernc.org/sqlite`) است که نیازی به gcc/CGO ندارد.

## سناریوی گفتگو در ربات

1. `/start` → نمایش لیست میوه‌ها به صورت دکمه‌های شیشه‌ای (inline keyboard).
2. با زدن روی یک میوه، قیمت هر کیلو، حداقل وزن قابل سفارش و یک انتخاب‌گر وزن
   (➖ / ➕ با گام ۰.۵ کیلوگرم، از حداقل وزن همان میوه شروع می‌شود) نشان داده می‌شود؛
   با زدن «افزودن به سبد خرید» آن قلم به سبد اضافه می‌شود.
3. کاربر می‌تواند چند میوه مختلف اضافه کند و در نهایت روی «مشاهده سبد خرید و ثبت سفارش»
   بزند.
4. سپس آدرس کامل و شماره تماس به صورت پیام متنی از کاربر گرفته می‌شود.
5. فاکتور نهایی نمایش داده می‌شود: ریز اقلام، جمع کل، یادآوری «ارسال ما رایگانه»،
   مبلغ ثابت ودیعه (پیش‌فرض ۲۰۰,۰۰۰ تومان) و مابقی مبلغ که پس از تحویل سفارش دریافت
   می‌شود.
6. با زدن دکمه پرداخت ودیعه، شماره کارت برای واریز نمایش داده می‌شود؛ کاربر تصویر رسید
   را ارسال می‌کند، سفارش در پایگاه داده ثبت نهایی می‌شود و (در صورت تنظیم) خلاصه سفارش
   + تصویر رسید برای چت مدیر ارسال می‌شود.

> توجه: پرداخت ودیعه از طریق واریز کارت‌به‌کارت و ارسال رسید انجام می‌شود، نه یک درگاه
> پرداخت آنلاین. برای اتصال به درگاه پرداخت واقعی (مثل زرین‌پال) نیاز به اطلاعات پذیرنده
> و کار اضافه‌تری است.

## پنل ادمین (وب)

با تنظیم `ADMIN_USERNAME` و `ADMIN_PASSWORD`، یک پنل وب ساده (با Basic Auth) روی پورت
`ADMIN_LISTEN_ADDR` (پیش‌فرض `:8080`) بالا می‌آید:

- **`/fruits`** — لیست همه میوه‌ها با امکان ویرایش «قیمت هر کیلو» و «حداقل وزن قابل
  سفارش» برای هرکدام؛ تغییرات بلافاصله در پایگاه داده ذخیره و در ربات اعمال می‌شود
  (بدون نیاز به ری‌استارت ربات).
- **`/orders`** — فهرست سفارش‌های ثبت‌شده (اقلام، جمع کل، ودیعه، آدرس، شماره تماس).

اگر این دو متغیر تنظیم نشوند، پنل ادمین اصلاً اجرا نمی‌شود (برای جلوگیری از بالا آمدن
یک پنل بدون رمز عبور).

## ساخت و اجرا

```bash
cd balebot
go build -o balebot .
```

متغیرهای محیطی:

| متغیر | الزامی | توضیح |
|---|---|---|
| `BALE_BOT_TOKEN` | بله | توکن ربات، از طریق ربات «BotFather» در بله ساخته می‌شود. |
| `DB_PATH` | خیر | مسیر فایل پایگاه داده SQLite (پیش‌فرض `balebot.db` در دایرکتوری جاری). |
| `ADMIN_CHAT_ID` | خیر | شناسه چت مدیر/فروشنده برای دریافت خودکار سفارش‌های جدید و تصویر رسید. |
| `DEPOSIT_AMOUNT` | خیر | مبلغ ودیعه به تومان (پیش‌فرض `200000`). |
| `DEPOSIT_CARD_NUMBER` | خیر | شماره کارت مقصد واریز ودیعه. |
| `DEPOSIT_CARD_HOLDER` | خیر | نام صاحب کارت. |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | خیر (اما برای فعال شدن پنل ادمین هر دو لازم‌اند) | ورود به پنل مدیریت میوه‌ها/سفارش‌ها. |
| `ADMIN_LISTEN_ADDR` | خیر | آدرس/پورت پنل ادمین (پیش‌فرض `:8080`). |

اجرا:

```bash
BALE_BOT_TOKEN="..." \
DB_PATH="/var/lib/balebot/balebot.db" \
ADMIN_CHAT_ID="123456789" \
DEPOSIT_CARD_NUMBER="6037-xxxx-xxxx-xxxx" \
DEPOSIT_CARD_HOLDER="نام و نام خانوادگی" \
ADMIN_USERNAME="admin" \
ADMIN_PASSWORD="یک-رمز-قوی" \
./balebot
```

ربات با استفاده از long polling (`getUpdates`) اجرا می‌شود و نیازی به وب‌هوک یا دامنه
عمومی ندارد. روی سرور، بهتر است آن را به‌صورت یک سرویس systemd اجرا کنید تا با ری‌استارت
سرور خودش هم بالا بیاید؛ اگر پنل ادمین را روی اینترنت عمومی در دسترس می‌گذارید، حتماً
پشت HTTPS (مثلاً nginx reverse proxy) قرار بدهید چون Basic Auth بدون HTTPS رمز عبور را
به‌صورت متن ساده روی شبکه می‌فرستد.

## داده اولیه و مدل داده

هنگام اولین اجرا (وقتی پایگاه داده خالی باشد)، لیست ۱۹ میوه اولیه با قیمت‌های داده‌شده
به‌صورت خودکار در جدول `fruits` درج می‌شود (`db/seed.go`). این مقادیر فقط پیش‌فرض اولیه
هستند و بعد از آن، **قیمت و حداقل وزن هر میوه باید از پنل ادمین (`/fruits`) تغییر داده
شود**، نه از کد.

جدول `orders` هم هر سفارش نهایی‌شده (بعد از دریافت رسید ودیعه) را با ریز اقلام، جمع کل،
ودیعه، آدرس و شماره تماس نگه می‌دارد.
